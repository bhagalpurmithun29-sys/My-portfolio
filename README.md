# Mithun Kumar | AI Developer Portfolio

A premium, high-fidelity personal portfolio website designed for an AI Developer. Built with a focus on modern aesthetics, this portfolio features a deep dark theme, glassmorphism UI components, and smooth cinematic animations.

## ✨ Features

- **Premium UI/UX:** High-end aesthetic with a custom dark theme (`#0B0B0F`), neon glows (blue and purple), and glassmorphic panels.
- **Cinematic Loading Screen:** A professional, fully animated loader featuring a segmented capsule progress bar and a blur-in text reveal.
- **Interactive Animations:** Powered by Framer Motion, featuring smooth scroll reveals, hover states, and dynamic elements like the glowing profile ring.
- **Responsive Design:** Fully optimized for both desktop and mobile viewing.
- **Modular Sections:**
  - **Hero:** Impactful introduction with an animated profile ring and direct call-to-actions.
  - **About & Skills:** Detailed bio and a categorized grid of technical skills.
  - **Projects:** Featured AI/ML projects with integrated assets and tech stack tags.
  - **Education & Experience:** Clean vertical timeline.
  - **Resume Preview:** Direct download access to the full PDF resume.
  - **Contact:** Interactive form and quick-contact social links.

## 🛠️ Tech Stack

- **Core:** React, Vite
- **Styling:** Vanilla CSS (utilizing CSS Variables for the design system)
- **Animations:** Framer Motion
- **Icons:** Lucide React

## 🚀 Getting Started

To get this project up and running locally, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository (if applicable) or navigate to the project directory:
   ```bash
   cd portfolio
   ```

2. Install the dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173/`
